---
title: "Конфигурация"
description: "Переменные окружения и флаги CLI, поддерживаемые PowerDNS Web UI."
---

PowerDNS Web UI читает конфигурацию из переменных окружения и опционального
файла `.env` в рабочем каталоге.

Флаги CLI могут переопределить хост и порт прослушивания.

## Переменные окружения

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `PDNS_API_URL` | `http://localhost:8081` | Базовый URL HTTP API PowerDNS Authoritative |
| `PDNS_API_KEY` | `changeme` | API-ключ, отправляемый в PowerDNS как `X-API-Key` |
| `PDNS_SERVER_ID` | `localhost` | Идентификатор сервера PowerDNS, используемый в путях API |
| `HOST` | `0.0.0.0` | Интерфейс, на котором слушает веб-интерфейс |
| `PORT` | `8080` | Порт, на котором слушает веб-интерфейс |

## Пример `.env`

```dotenv
PDNS_API_URL=http://127.0.0.1:8081
PDNS_API_KEY=replace-with-your-api-key
PDNS_SERVER_ID=localhost
HOST=127.0.0.1
PORT=8080
```

## Флаги CLI

| Флаг | Описание |
| --- | --- |
| `-host` | Хост или интерфейс для прослушивания |
| `-port` | Порт для прослушивания |
| `-h` | Вывести справку |

Пример:

```bash
pdns-webui -host 127.0.0.1 -port 8080
```

## Идентификатор сервера PowerDNS

В большинстве установок PowerDNS в качестве идентификатора сервера используется
`localhost`. Если ваш API PowerDNS использует другой идентификатор, задайте
`PDNS_SERVER_ID` так, чтобы он совпадал.

## Флаг отладки

`.env.example` также содержит:

```dotenv
DEBUG=false
```

Текущий код сервера не использует `DEBUG`. Считайте его зарезервированным для
инструментов разработки, а не функциональным переключателем приложения.
