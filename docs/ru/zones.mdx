PowerDNS Web UI управляет authoritative-зонами через API PowerDNS.

## Типы зон

Поддерживаемые типы зон:

- `Native`
- `Master`
- `Slave`

Используйте `Native` для обычных автономных authoritative-зон. Используйте
`Master` и `Slave`, когда работаете с топологией первичных и вторичных
DNS-серверов.

## Создание зоны

При создании зоны указывайте полное доменное имя зоны:

```text
example.com.
```

Точка в конце важна. Она делает имя абсолютным и устраняет неоднозначность.

## Уведомление вторичных серверов

Для master-зон используйте уведомление, чтобы попросить настроенные slave-серверы
обновить свою копию зоны.

Это соответствует endpoint уведомления зон в PowerDNS.

## Экспорт зоны

Экспорт зоны показывает исходный файл зоны, возвращённый PowerDNS. Используйте
его, когда нужно посмотреть сгенерированные записи, скопировать зону или
проверить, что именно будет отдавать PowerDNS.

## Получение slave-зоны

Для slave-зон AXFR-получение просит PowerDNS передать зону с настроенного
master-сервера.

Если получение не удалось, проверьте:

- Адрес master, настроенный для зоны
- Метаданные `ALLOW-AXFR-FROM` на master
- Сетевую доступность между вторичным и первичным серверами
- Правила межсетевого экрана для TCP/UDP 53
