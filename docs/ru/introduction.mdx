---

PowerDNS Web UI — это небольшое приложение на Go, которое предоставляет
браузерный интерфейс для PowerDNS Authoritative Server и проксирует запросы к
встроенному HTTP API PowerDNS.

Он создан для администраторов, которым нужна прямая и лёгкая панель управления
DNS-зонами без раскрытия API-ключа PowerDNS в браузере.

## Что можно настраивать

- Authoritative-зоны: просмотр, создание, редактирование, удаление, уведомление вторичных серверов и экспорт файлов зон
- DNS-записи: `A`, `AAAA`, `ALIAS`, `CAA`, `CNAME`, `MX`, `NS`, `PTR`, `SOA`, `SRV` и `TXT`
- RRset с несколькими значениями для записей `A`, `AAAA`, `NS` и `TXT`
- Slave-зоны, включая AXFR-передачу с настроенного master-сервера
- Метаданные зон, такие как `ALLOW-AXFR-FROM`, `AXFR-SOURCE`, `SOA-EDIT` и `SOA-EDIT-API`
- Autoprimary для автоматического создания вторичных зон

## Как это работает

Браузер взаимодействует только с PowerDNS Web UI. Бэкенд на Go добавляет
заголовок `X-API-Key` и перенаправляет запросы в PowerDNS.

```text
браузер -> PowerDNS Web UI -> PowerDNS HTTP API
```

API-ключ PowerDNS остаётся на сервере.

## Важная модель безопасности

PowerDNS Web UI не предоставляет собственной аутентификации или авторизации.

Запускайте его за доверенными средствами контроля доступа: в приватной сети,
через VPN, с правилами межсетевого экрана или за обратным прокси с
аутентификацией. Не открывайте его напрямую в публичный интернет, если только
вы не хотите подарить незнакомцам административные кнопки управления DNS.
Смелая стратегия, но не лучшая.
