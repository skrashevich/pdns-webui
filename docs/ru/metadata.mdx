---
title: "Метаданные зоны"
description: "Управление метаданными зон PowerDNS и autoprimary."
---

Метаданные зон PowerDNS управляют поведением, которое не представлено
обычными DNS-записями.

PowerDNS Web UI предоставляет доступ к распространённым метаданным,
используемым для передачи зон и обработки серийного номера SOA.

## Поддерживаемые метаданные

| Метаданные | Назначение |
| --- | --- |
| `ALLOW-AXFR-FROM` | IP-адреса или диапазоны, которым разрешён AXFR этой зоны |
| `ALSO-NOTIFY` | Дополнительные nameserver-ы или IP, которым отправлять уведомления после изменений зоны |
| `AXFR-SOURCE` | Адрес-источник, который PowerDNS использует для исходящих AXFR-запросов |
| `SOA-EDIT` | Политика изменения серийного номера SOA при изменениях зоны |
| `SOA-EDIT-API` | Политика изменения серийного номера SOA при изменениях через API |

## ALLOW-AXFR-FROM

Используйте `ALLOW-AXFR-FROM` на первичной зоне, чтобы разрешить вторичным
серверам передавать её.

Примеры значений:

```text
192.0.2.10
2001:db8::10
```

## Поведение серийного номера SOA

`SOA-EDIT` и `SOA-EDIT-API` управляют тем, как PowerDNS изменяет серийные
номера SOA после изменений зоны.

Выбирайте политику, соответствующую вашей операционной модели. Если ваши
вторичные серверы зависят от увеличения серийного номера, убедитесь, что
изменения через API последовательно обновляют его.

## ALSO-NOTIFY

Используйте `ALSO-NOTIFY`, когда хотите, чтобы PowerDNS отправлял уведомления
дополнительным вторичным серверам помимо стандартных целей, выведенных из NS.

Указывайте по одному получателю на строку, например:

```text
192.0.2.53
2001:db8::53
ns-secondary.example.net
```

## Autoprimary

Autoprimary позволяет PowerDNS автоматически создавать вторичные зоны, когда
доверенный первичный сервер отправляет уведомление.

PowerDNS Web UI может выводить, создавать и удалять записи autoprimary через
API PowerDNS.
