---
title: "Записи"
description: "Управление DNS RRset и поддерживаемыми типами записей."
---

PowerDNS Web UI редактирует записи как RRset PowerDNS.

RRset — это сочетание имени записи, типа, TTL и одного или нескольких значений.

## Поддерживаемые типы

Поддерживаемые типы записей:

- `A`
- `AAAA`
- `ALIAS`
- `CAA`
- `CNAME`
- `MX`
- `NS`
- `PTR`
- `SOA`
- `SRV`
- `TXT`

## Записи с несколькими значениями

Для типов записей, у которых обычно бывает несколько значений, добавляйте
каждое значение в один и тот же RRset, а не создавайте дубликаты строк
name/type.

Примеры:

- Несколько записей `A` для round-robin ответов IPv4
- Несколько записей `AAAA` для ответов IPv6
- Несколько записей `NS` для делегирования
- Несколько строк `TXT` для верификационных записей

## Относительные и абсолютные имена

Используйте `@` для apex зоны.

Используйте относительное имя, например `www`, для записи внутри текущей зоны.
UI развернёт его относительно имени зоны.

Используйте точку в конце для полностью определённого имени:

```text
target.example.net.
```

## Записи ALIAS

PowerDNS Authoritative обслуживает записи `ALIAS` только при настроенном
расширении ALIAS.

Для PowerDNS 5.1 настройте резолвер, который не указывает обратно на сам
authoritative-сервер:

```ini
resolver=[::1]:5300
expand-alias=yes
```

PowerDNS Web UI рассматривает `ALIAS` как запись только для apex и принимает
ровно одну цель на RRset.

Используйте:

```text
@
```

в качестве имени записи и одну полностью определённую цель:

```text
target.example.net.
```

## Записи SOA

UI отображает записи SOA, но это специальные записи, управляемые поведением
зон PowerDNS. Для управления обновлением серийного номера используйте
метаданные зоны, такие как `SOA-EDIT` и `SOA-EDIT-API`.
